# NusaFit V14 — Penyesuaian navigasi desain

- Menyesuaikan navigasi bawah menjadi lima menu seperti referensi: Beranda, Riwayat, Peta GPS, Statistik, Profil.
- Tombol START tetap tersedia sebagai tombol bulat di layar Beranda (bukan sebagai tab navigasi terpisah).
- Memperbaiki pemetaan indeks navigasi agar menu Peta GPS, Statistik, dan Profil membuka layar yang sesuai.
- Mempertahankan menu olahraga, kontrol tracking, riwayat, statistik, profil, dan pemilihan foto dari basis V13.

Catatan validasi: perubahan sumber dilakukan, tetapi build Android dan uji perangkat nyata tidak dijalankan dalam lingkungan ini. Google Maps tetap membutuhkan API key yang sah serta izin/lokasi perangkat aktif.
